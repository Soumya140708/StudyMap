# StudyMap

A student-focused learning resource website that organises study material around the syllabus, so students can see what to study next, prepare before class and revise afterwards.

> **Status:** Static frontend project (HTML, CSS, JavaScript). It has no backend, database, login or file-upload system. Progress figures and the sample content are hard-coded for demonstration.

## Problem Statement

Study material is often scattered across textbooks, Classroom, WhatsApp messages, PDFs and websites. Students may not know which topic comes next in their syllabus, and revision becomes harder before exams. StudyMap puts subjects, units, topics and resources into one clear path.

## Objectives

- Let students explore subjects by semester
- Present the syllabus as a clear roadmap of units and topics
- Keep notes, revision material and practice questions together for each topic
- Help students prepare before a topic is taught in class

## Features

- **Syllabus navigation:** Semester → Subject → Unit → Topic
- **Learning resources page** for each topic, with filter buttons (All, Faculty Notes, Reference, Quick Revision, Practice)
- **Faculty notes** with definitions, examples and a sample program
- **Quick revision sheet** with key definitions, a data-type table and exam-ready questions
- **Interactive practice quiz:** 5 multiple-choice questions with score and feedback
- **Dashboard and My Progress pages** showing sample progress bars
- **Responsive layouts** for desktop and mobile

## Sample Content

The complete learning path is built for one topic: **Programming → Unit 01 → Variables and Data Types**. Other subjects (Mathematics, Computer Fundamentals, Web Technology) and Semesters 02–04 appear in the interface as placeholders for future content.

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, quiz logic)

## How to View the Project

1. Download this repository (**Code → Download ZIP**) and extract it.
2. Open `index.html` in any web browser.

No installation is needed.

## Limitations

- Static prototype: no database, accounts or real progress tracking
- Progress percentages are sample values
- Faculty upload and syllabus-update features described on the Explore and About pages are planned ideas, not implemented
- Only one topic has full content

## Future Improvements

- Teacher upload system for notes and resources
- Real progress tracking with student accounts
- Content for the remaining subjects and semesters
- Support for additional courses and departments
