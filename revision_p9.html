Variables and Data Types

A quick revision sheet containing the most important concepts, definitions and examples you should remember before a test or exam.

📌 1. Variable

A variable is a named location used to store a value in a program.

Remember:

Variable = Name + Stored Value

📊 2. Data Type

A data type specifies the kind of value that a variable can store.

  • Integer → Whole numbers
  • Float → Decimal numbers
  • String → Text
  • Boolean → True or False

📝 3. Important Data Types

Data Type Example
Integer 25
Float 25.5
String "Hello"
Boolean True

💻 4. Example

name = "Student"
age = 18
marks = 85.5
passed = True

Each variable stores a different type of value.

⭐ Remember These

  • Variables are used to store values.
  • A variable can contain different types of data.
  • Integer stores whole numbers.
  • Float stores decimal numbers.
  • String stores text.
  • Boolean represents True or False.
