Learn

A variable is a named location used to store a value in a program.

Variable
A variable stores information that can be used by a program.
Data Type
A data type tells us what kind of value is being stored.

Example

name = "Soumya"
age = 18
marks = 85.5

Here, name stores text, age stores an integer and marks stores a decimal value.
