UNIT 01 • PROGRAMMING

Variables and Data Types

Faculty Notes
Understand the basic concept of variables and the different types of data used in programming.

📘 Faculty Notes

In programming, we often need to store information such as names, numbers and marks. A variable is used to store this information so that it can be used later in a program.

1. What is a Variable?

A variable is a named location used to store a value in a program. The value stored in a variable can be used or changed during program execution.

Example:

age = 18

Here, age is the variable and 18 is the value stored in it.

2. What is a Data Type?

A data type specifies the kind of value that a variable can store. Different types of information require different data types.

3. Common Data Types

  • Integer: Used for whole numbers. Example: 10, 25, 100
  • Float: Used for decimal numbers. Example: 10.5, 25.75
  • String: Used for text. Example: "Hello"
  • Boolean: Represents True or False.

4. Example Program

name = "Student"
age = 18
marks = 85.5
passed = True

print(name)
print(age)
print(marks)
print(passed)

5. Why are Variables Important?

  • They store information in a program.
  • They make programs easier to understand.
  • The stored values can be used multiple times.
  • The value of a variable can be changed when required.

6. Quick Summary

Variable → Stores a value.

Data Type → Defines the type of value.

Integer → Whole number.

Float → Decimal number.

String → Text.

Boolean → True or False.
